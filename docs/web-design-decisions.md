# Web design page decision log

What was decided for the web design service's page (`/services/web-design`), the project pages (`/work/[slug]`) and their previews, and why. Newest notes sit lower; when two notes disagree, the later one wins.

- 2026-10-09: the main service gets a page of its own (user's brief), `src/app/services/web-design/page.tsx` → `WebDesign` in `src/components/web-design.tsx`; the shared `/services/[slug]` page leaves web design out (`OWN_PAGE`). Copy is English, translated from the user's Portuguese, every piece of information kept. Asked once in a batch and answered "1A 2A 3A 4A, constrói com campos a preencher".
- Heading: "Web Design." (light) / "Websites that make a business stand out." (medium), with a side subtitle levelled by `useInkAlign`, as the home page's sections are. The page carries the floating bar and the footer, like the about page, and is `noindex` while its fields are placeholders.
- Section 1, the work (user picked A): the two projects (Bsmartish; Estacionamento de Gerona, still in production) hung as plates in one closed frame (`.wk-frame`: black hairline all round, a top bar with the black "Selected work" label and the project count, a black rule between the plates). Each plate is one link: an empty image (3:2, "Fig. 0n" in its corner; the user asked to leave the images empty for now), the name with an arrow, and fields as index rows (Sector, Scope, Status). When there are more projects, a "See all work" way in goes into this frame.
- The data is in `src/lib/work.ts`. Every field the studio has not given is `null` and reads "[a preencher]" (`TO_FILL`): sector, identity style, scope, year, the site's address and the words about it, for both projects. Nothing about the clients is made up.
- Project page (`/work/[slug]`, `project-page.tsx`): one section in the same frame: the name large above it, then an index (Company, Sector, Identity, Scope, Year, Status) beside the empty image, then "About the website" with "View the website". Gerona says "Website in production" instead of a button; Bsmartish says "Website address [a preencher]" until its URL is in.
- Preview (user picked A): "View the website" opens `/work/[slug]/preview` (`site-preview.tsx`), the live site in a bordered frame under the black bar, with Desktop / Tablet / Phone keys (full width, 834px, 390px) and "Open the live site". Whether a site lets itself be framed is checked on the server (`src/lib/embed.ts`: X-Frame-Options and CSP frame-ancestors, re-asked daily); where it does not, the button opens the site itself in a new tab and the preview route redirects to it.

(user picked A): three statements on one black rule, the page's one large-type moment: "Free hosting, / for life.", "Built / to be found.", "A free call, / a quarter of the way in.", each with its explanation. (user picked A; the brief's "Mesmo assim, assim deseja" read as "Mesmo assim, deseja"): the rule that changes are paid and priced before starting is the subtitle; two panels in a frame, Content (text, photos or videos: fixed price, a call to note the changes) and Style (animations, sections, colors or typography: a quote, started once approved).
