# Imagens da página Funcionalidades de Back End

Três lugares, já com o nome certo. Enquanto o ficheiro não existir, a
página mostra no lugar dele uma pequena interface animada (a mesma
forma, o mesmo tamanho), por isso basta largar o ficheiro aqui: não há
código nem layout a mexer.

| Ficheiro | O que é | Formato |
| --- | --- | --- |
| `pedidos.webp` | A base de dados de pedidos e contactos: uma tabela real, com os pedidos que entraram | 4:3 |
| `calendario.webp` | O calendário da atividade da empresa, com marcações ocupadas | 4:3 |
| `emails.webp` | Um e-mail automático ou um modelo pré-feito com os espaços a preencher | 4:3 |

Notas:

- 4:3, pelo menos 1200 px de largura, `.webp`.
- São capturas de ecrã de trabalho real. Qualquer nome, morada, telefone
  ou e-mail de cliente tem de ser trocado por dados inventados antes de
  a captura entrar aqui.
- Fundo claro, sem sombras nem molduras do sistema operativo: a página
  já dá a moldura.
